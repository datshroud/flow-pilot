# FlowPilot

An event-driven multi-domain workflow platform with permission-aware AI Agents.

One configurable core — metadata-driven entities, dynamic forms, a versioned
workflow engine, case/task management and a tool-calling AI agent — demoed
across three domains: procurement, recruitment and equipment maintenance.

## Stack

Next.js · Express 5 · TypeScript · PostgreSQL + Prisma · Apache Kafka ·
Redis + BullMQ · OpenTelemetry
